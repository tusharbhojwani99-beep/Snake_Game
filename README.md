# Snake_Game
A classic Snake Game built using HTML, CSS, and JavaScript. Control the snake, eat food, grow longer, and try to achieve the highest score without colliding!

👉 Play the Game
Live link - snake-game-js00.netlify.app

📌 Features
🎮 Smooth snake movement
🍎 Random food generation
📈 Score tracking system
🔊 Sound effects (start / game over)
⏱️ Adjustable game speed
🧠 Simple and clean game logic

🎯 How to Play
Use Arrow Keys to control the snake
Eat food to grow and increase score
Avoid hitting:
Walls
Yourself
